What it changes on your PC

It asks before restarting the PC and before the disk clean-up.

  • Windows: switches on Windows Subsystem for Linux and Virtual Machine Platform, runs wsl --update and wsl --set-default-version 2, and switches the Windows hypervisor back on if it was off.
  • %USERPROFILE%\.wslconfig is replaced with a new one (not merged); the old one is backed up first. The Linux disk is made sparse.
  • Fixed IP option: two lines in /etc/wsl.conf, a scheduled task Greenhorn-WSL-FixedIP (at logon and every 5 minutes), a helper script in C:\ProgramData\GreenhornWSL, and wsl.local in the hosts file. Everything is backed up first.
  • Disk clean-up, in every Linux distro except docker-desktop: clears the apt cache and package lists, trims the journal to 50 MB, and deletes everything in /tmp and /var/tmp.
  • Tortugarr step: downloads into Downloads\Tortugarr and puts the server install commands on the clipboard.
  • During the run only: the restart safety net and, if you use it, a temporary firewall rule for the APK shop. Both are removed again.
  • Left behind on purpose: a copy of the installer in C:\ProgramData\GreenhornWSL, so it can be run again later, and a log in %TEMP%.

Everything is in one readable file. Nothing to install first, no telemetry. It only talks to Microsoft (WSL and Ubuntu) and GitHub (the Tortugarr release). Found a bug? Open an issue.
